# 命令与参数

完整参数表与输出格式细节。总览见 [`../README.md`](../README.md),
界面用法见 [`使用说明.md`](使用说明.md)。

```
python -m shsynth <子命令> [选项]
```

装了包之后可以直接 `shsynth <子命令>`。

---

## 子命令

| 子命令 | 作用 |
| --- | --- |
| `synth` | **主功能**:系数 + 位置 → 值 + 图 |
| `info` | 看系数文件:布局 / 阶数 / 时次 / 物理量 / 逐阶谱 / 换算因子 |
| `convert` | 只换表示:改布局、换物理量、截断、平滑,再写一份 |
| `formats` | 列出支持的全部文件格式与物理量 |
| `selftest` | 自检:解析解 + scipy 对照 + 与 SHKit 逐位比对 |
| **`series-read`** | **v2.0**:一个 `GSM-*.gfc` 目录 / 清单 → **带真实日期**的系数序列 |
| **`series-synth`** | **v2.0**:批量综合整条序列 → 场序列 `.nc`(带时间坐标)+ 逐历元诊断 `.csv` |
| **`series-points`** | **v2.0**:站点/散点时间序列(可含水平形变两个分量) |
| **`series-fit`** | **v2.0**:系数域趋势 + 周年拟合 → 趋势场 / cos·sin 场 / 参数表 |
| **`series-basin`** | **v2.0**:流域/区域平均时间序列(**两种口径都算并对比**) |

> v2.0 的三条主线:**多时间批量处理**、**水平形变 u_N/u_E**、**FFT 经度快路径**。
> 规划与实测见 [`多时间数据批量处理方案.md`](多时间数据批量处理方案.md);
> 实测脚本在 [`probes/`](probes/)。
>
> **命令行怎么跑**:冻结版是 GUI 程序,所以命令行要经 `--cli` 转给命令行接口:
> `SHSynth.exe --cli series-synth --coeffs …`。v2.0 修掉了一个会让 `--cli`
> **完全不可用**的缺陷(windowed exe 没有接上父控制台 → `print()` 抛
> `OSError: [Errno 22] Invalid argument`);现在启动时会自动接回父控制台,
> 而且即使实在写不出去,**计算也照常完成、结果照常落盘**(输出会存到
> `%TEMP%\SHSynth_cli_output.txt` 并回报路径)。

## `series-read`(v2.0)

一个目录 = 一条系数序列。日期**头优先、文件名兜底**。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--indir` | **必填** | gfc 目录 / glob / `.txt` 清单 / 单个多时间文件 |
| `--product` | `GSM` | 只收这些前缀;**混入 GAC/GAD 会报错**(它们不是 GSM,会静默改变物理含义) |
| `--pattern GLOB` | `*.gfc` | 目录内的匹配式 |
| `--mission` / `--center` / `--rl` | — | 按 `GRAC`/`UTCSR`/`0600` 之类片段过滤 |
| `--no-recursive` | 递归 | ITSG 日解按年份分目录,**默认要递归** |
| `--epoch-from` | `auto` | `auto`(头→文件名)/`header`/`filename`/`index` |
| `--sort` | `time` | `time`/`name`/`none` |
| `--on-duplicate` | `error` | `error`/`first`/`last`/`report`;**绝不静默取一个** |
| `--lenient-nmax` | 严格 | 各文件最高阶不一致时,默认**报错**而不是零填充 |
| `--out FILE` | **必填** | `.nc`(推荐,`series_nc` 契约)/ `.dat`(legacy 三角 + 时间表) |
| `--summary FILE` | — | 把时间轴摘要写出去 |

```bash
python -m shsynth series-read --indir "..\2_unzipped\1_CSR\01RL06\01deg60" \
    --out out/csr60_series.nc --summary out/csr60_times.txt
```

输出示例(实测 203 个真实文件):

```
时间轴: 203 个历元
  跨度      : 2002-04-18 .. 2021-11-16
  相邻间隔  : min 10 / 中位 30 / max 371 天(不规则)
  缺测      : 20 处  1→2 差 98 天, …
  日期来源  : gfc_header
```

## `series-synth`(v2.0)

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--coeffs FILE` | **必填** | 序列(`.nc` / legacy `.dat` / `.npz` …) |
| `--global-grid DEG` | — | 全球网格;**整圈均匀经度时自动走 FFT 快路径** |
| `--lat-min/--lat-max/--lon-min/--lon-max/--lat-step/--lon-step` | — | 范围网格(区域经度走直接法) |
| `--grid-file FILE` | — | 借用已有网格的格点 |
| `--points FILE` | — | 散点(散点只能用直接法) |
| `--gaussian-km KM` | 0 | 空间高斯平滑(只施加一次) |
| `--target-unit UNIT` | 不换算 | `ewh`/`geoid`/…/`horizontal_displacement` |
| `--component` | `scalar` | `scalar`/`north`/`east`/`horizontal`(矢量) |
| `--scale` | `1` | `1`(SI)/`mm`(×1e3 并改写 `units`) |
| `--remove-mean` | 关 | 先去**全时段**时间平均 → **异常场**(GSM 含静态场,强烈建议)。 |
| `--remove-mean-mode MODE` | 关 | **去均值口径**:`grace`(GRACE 惯例 2004-2010)/`all`(全时段,等同 `--remove-mean`)/`custom`(自定义)。给了它就隐含要做去均值 |
| `--mean-from` / `--mean-to` | — | 自定义窗口起止(`YYYY-MM-DD`/`YYYY-MM`/`YYYY`/十进制年) |
| `--drop-degree0 N` | — | 把 `n≤N` 的系数置零 |
| `--use-fft` | `auto` | `auto`/`yes`/`no`;报告里会**写明走了哪条路** |
| `--time-chunk N` | 32 | FFT 路径内部的时间分块(不改变结果) |
| `--out FILE` | — | 场序列 `.nc`(带**真实时间坐标**;矢量时一个文件装北/东) |
| `--out-summary FILE` | — | 逐历元诊断表 `.csv` |
| `--time-encoding` | `datetime64` | `datetime64`(与 `3_grids` 同构)/ `cf`(int32+units) |
| `--anim-out FILE` | — | **v2.0 动画**:`.gif`(只需 Pillow,推荐)或 `.mp4`(需 imageio+ffmpeg) |
| `--anim-fps FPS` | 5 | 帧率;GIF 延时只能取 10 ms 整数倍,**实际值会打印出来** |
| `--anim-stride N` | 1 | 每隔 N 个历元取一帧(默认每个历元一帧) |
| `--anim-vmin/--anim-vmax` | 全序列稳健范围 | 配色范围;**默认在全序列上定一次**,不逐帧定标 |
| `--anim-focus` | `global` | 动画默认全球视图(逐帧聚焦会让视野一直晃) |
| `--anim-title TEXT` | 自动 | 每帧标题前缀 |

```bash
# 标量场序列(1° 全球,203 历元实测约 0.3 秒)
python -m shsynth series-synth --coeffs out/csr60_series.nc --global-grid 1 \
    --gaussian-km 300 --target-unit ewh --remove-mean \
    --out out/ewh_series.nc --out-summary out/ewh_diag.csv

# 水平形变矢量(一个 nc 里装 north/east_displacement + 时间坐标)
python -m shsynth series-synth --coeffs out/csr60_series.nc --global-grid 1 \
    --component horizontal --scale mm --remove-mean \
    --out out/uh_series.nc

# 顺带出一张 GIF 动图(2° 网格、每 5 个历元一帧、8 fps,实测约 1 MB)
python -m shsynth series-synth --coeffs "..\2_unzipped\1_CSR\01RL06\01deg60" \
    --global-grid 2 --nmax 60 --target-unit ewh --remove-mean \
    --anim-out out/ewh.gif --anim-fps 8 --anim-stride 5
```

**动画的配色必须固定**:逐帧各自定标的话,动画会随每历元的极值"闪",
眼睛看到的"变化"其实是配色在变。所以 `--anim-*` 默认取**全序列**的稳健对称范围,
并把实际范围打印出来。想要 `.mp4` 就得装 `imageio` + `imageio-ffmpeg`;
**没装会明确报错并让你改用 `.gif`,不会把视频悄悄降级成一张静止图。**

**速度怎么来的**:整圈均匀经度上把"逐点显式展开经度"换成一次 FFT ——
实测 1°×203 历元从 ~10 s 降到 **0.3 s**(30~130×,见方案 §6.5)。
不满足条件(区域经度 / 散点 / `nlon ≤ 2·nmax`)会**自动回退直接法并说明**。

### 输入目录也能直接用

`series-synth` / `series-points` / `series-fit` / `series-basin` 的 `--coeffs`
除了序列文件,**也可以直接给一个装着 `GSM-*.gfc` 的目录**(内部自动走
`series-read` 那套识别逻辑),省得为了看一眼流域平均先手动导出一次。

### 去均值:三种口径(四个序列命令通用)

去均值决定整个异常场的**静态基准**,所以不是个开关而是**三选一**,且默认**不做**。

| 参数 | 说明 |
| --- | --- |
| *(不给)* | 不做(输出是含静态场的原始场) |
| `--remove-mean` | **全时段**平均。与 v2.0 早期行为**逐位一致** |
| `--remove-mean-mode grace` | **GRACE 惯例**:减 2004-01-01 .. 2010-12-31 的平均 |
| `--remove-mean-mode all` | 同 `--remove-mean` |
| `--remove-mean-mode custom --mean-from A --mean-to B` | **自定义**窗口 |

给了 `--remove-mean-mode` 就**隐含**要做去均值(不必再写 `--remove-mean`)。
日期写法宽松:`2004-01-01` / `2004-01` / `2004` / `2004.5` 都认;
**起点补 01-01、终点补 12-31**(所以 `--mean-to 2009` 是到 2009 年底,
不会少算 11 个月)。`--drop-degree0 N` 同样这四个命令都支持。

```bash
# GRACE 惯例(2004-2010)
python -m shsynth series-synth --coeffs out/csr60_series.nc --global-grid 1 \
    --target-unit ewh --remove-mean-mode grace --out out/ewh.nc

# 复刻 legacy 脚本里的 19:90(其实是 2004-2009)
python -m shsynth series-synth --coeffs out/csr60_series.nc --global-grid 1 \
    --target-unit ewh --remove-mean-mode custom \
    --mean-from 2004-01-01 --mean-to 2009-12-31 --out out/ewh_0409.nc
```

运行时会打印**实际**用了哪一段:

```
  预处理      : 去均值口径 = GRACE 惯例:减 2004-01-01 .. 2010-12-31 的平均;
                实用 84/203 个历元(2004-01-07 .. 2010-12-14,占 41.4%)
```

窗口里一个历元都没有时会**报错**(退出码 2)并给出序列的真实跨度 ——
**绝不退化成全时段**(那会悄悄换掉静态场基准)。

> ⚠️ **legacy 脚本的 `dur_mascon` 与它自己的注释对不上**。实测
> `read_GRACE_SH_preprocess_postprocess_SH60.m` 里的 `dur_mascon = 90:150`
> 在 CSR RL06(203 历元)上落到 **2009-12..2016-01**,而注释写的是
> "remove the mean of 2004-2010";同一段代码在 GRACE-FO 版里是 `19:90`
> (对应 2004-01..2009-12)。所以 v2.0 **按日期**定口径,不看索引。
> 详见方案 §4.4.2 与探针 `docs/probes/_probe_demean.py`。

## `series-basin`(v2.0)

流域/区域平均时间序列。**两种口径都算,并把差异明确报出来。**

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--mask FILE` | **必填** | 掩膜:二维数组的 `.nc`/`.grd`/`.csv`,或 `[lon;lat;value]` 堆叠的 `.npy` |
| `--mask-lat-step` / `--mask-lon-step` | 180/nlat、360/nlon | **裸二维 `.npy`** 才需要(那种文件不带坐标轴) |
| `--mask-kernel FILE` | — | **只用来建球谐核**的更细掩膜 —— 给了才有真实差异可比 |
| `--nmax N` | 序列最高阶 | 平均时截断到该阶 |
| `--method` | `both` | `coeff` / `spatial` / `both` |
| `--out FILE` | — | `.csv`(含 `date, decimal_year, spatial, coeff, diff`) |

```bash
python -m shsynth series-basin --coeffs out/csr60_series.nc \
    --mask basin.npy --nmax 60 --out out/basin.csv
```

⚠️ **两个口径不是两个答案**。当 `coeff` 建核用的掩膜格点与 `spatial` 综合用的
格点是**同一套**、`nmax` 也相同时,两者**代数上恒等**(实测相对差 6e-16 … 5e-15):

```
Σ_{n≤L,m} f_nm·g_nm  =  Σ_i w_i·f^L(x_i)
```

`coeff` 的价值是**算得快**:核只建一次,之后每历元只要 `O(nSHCS)` 的内积。
实测 203 历元 / nmax=60 / 6516 格点掩膜:**`spatial` 1.059 s vs `coeff` 0.022 s(48×)**。

所以 `series-basin` 会**断言两者恒等**(互为交叉验证);差异显著大于舍入
说明实现有 bug,不是"两种方法本就不同"。想看真实差异,用 `--mask-kernel`
给一张更细的掩膜建核 —— 现实中流域边界是高分数字化的、场只在粗网格上算,
这才是两个口径该比的东西。实测(参考 = 360×720 细网格 `spatial`):

| 粗网格 | `spatial` 相对参考 | `coeff`(细核)相对参考 |
| --- | --- | --- |
| 45×90 | 1.21e-05 | **4.44e-15** |
| 90×180 | 1.64e-07 | **4.44e-15** |
| 180×360 | 3.75e-08 | **4.44e-15** |

细核的 `coeff` **完全不随粗掩膜网格变化**;`spatial` 的掩膜边界误差随网格变粗按 Δ² 增大。

## `series-points` / `series-fit`(v2.0)

```bash
# 站点时间序列(长表:一行 = 一个点一个历元)
python -m shsynth series-points --coeffs out/csr60_series.nc --points sites.csv \
    --component horizontal --scale mm --out out/sites_uh.csv

# 系数域趋势 + 周年(与逐点拟合机器精度一致,但快得多)
python -m shsynth series-fit --coeffs out/csr60_series.nc --periods 1,0.5 \
    --trend linear --out-trend out/trend.nc --out-seasonal out/seasonal.nc \
    --out-table out/fit.csv
```

`series-fit` 的 `--out-seasonal` 会写两份:`*_cos1.nc` 与 `*_sin1.nc`
(周期项按 `cos`/`sin` 两列给出,振幅 = `hypot`,`相位 = atan2`)。

## `synth`

### 系数输入

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--coeffs FILE` | **必填** | `.sh .txt .csv .dat .tsv .gfc .npy .npz .nc`(+`.gz`) |
| `--layout` | `auto` | `auto/triangle/gmfcsv/matrix/gfc/npy/npz/series_nc/series_dat` |
| `--coeff-nmax N` | 文件自身 | 读取时截断 |
| `--time K` | 0 | 多时次选第 K 个(**仍是单历元**;批量请用 `series-synth`)|

### 求值位置(互斥)

| 参数 | 说明 |
| --- | --- |
| `--global-grid DEG` | 全球网格经度 `0..360` **不含端点**,纬度 `-90..90` 含端点 |
| `--grid-file FILE` | 借用该网格文件的格点 |
| `--grid-var NAME` | 配 `--grid-file`,指定 netCDF 变量 |
| `--points FILE` | 用该散点文件的经纬度 |
| `--lat-col COL` / `--lon-col COL` | 列名或 0 基下标;留空自动识别 |
| `--sphere-points N` | 不给点位时的 Fibonacci 球面点数(默认 20000) |
| `--lat-min/--lat-max/--lon-min/--lon-max/--lat-step/--lon-step` | 范围网格,默认 `-90/90/0/360/1/1` |

### 综合选项

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--nmax N` | 系数自身 | 截断到 N 阶 |
| `--gaussian-km KM` | 0 | 高斯平滑半径(综合时施加,不改系数文件) |
| `--gaussian-method` | `glq` | `glq`(稳定) / `frc`(快,高阶不稳) |
| `--target-unit UNIT` | 不换算 | `geoid` / `ewh` / `surface_density` / `radial_displacement` / `geopotential`,也接受中文 |
| `--allow-unit-mismatch` | 关 | 物理量声明矛盾时仍强行换算(仅实验) |
| `--chunk N` | 200000 | 每块点数(只影响内存,不影响数值) |

### 输出

| 参数 | 说明 |
| --- | --- |
| `--out FILE` | 网格 `.nc/.grd/.npy/.csv/.txt/.dat`;散点 `.csv/.txt/.dat/.tsv/.npy` |
| `--var NAME` | netCDF 变量名(默认 `value`) |
| `--units TEXT` | 写进 netCDF/图上的单位说明(**只标注,不换算**) |
| `--comment TEXT` | 注释/历史记录 |
| `--out-coeffs FILE` | 顺带把截断/平滑后的系数写一份 |
| `--out-coeffs-layout` | 系数输出布局(默认按扩展名) |

### 出图

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--figure FILE` | 无 | `.png/.pdf/.svg/.jpg` |
| `--figure-kind` | `report` | `report`/`map`/`spectrum`/`hist`/`none` |
| `--dpi N` | 160 | |
| `--cmap NAME` | `RdBu_r` | 异常场用发散色系更直观 |
| `--contour` | 关 | 网格图叠加等值线 |
| `--no-coast` | 关 | 不画海岸线 |
| `--focus` | `auto` | `auto` 区域数据自动缩放到结果范围;`global` 强制全球视图 |
| `--asymmetric-range` | 关 | 配色不关于 0 对称(默认对称) |
| `--quiet` | 关 | 只打印一行结果 |

## 输出格式细节

### 网格

| 扩展名 | 说明 |
| --- | --- |
| `.nc` | CF 风格 netCDF,变量名可指定;全局属性里带 `shsynth_meta`(来源系数、阶数、平滑半径、物理量) |
| `.grd` | Surfer ASCII `DSAA`;行序 y 递增(南→北);只支持单层(多时次请用 `.nc`) |
| `.npy` | `(3, nlat, nlon)` 的 `[lon; lat; value]` 堆叠;只支持单层 |
| `.csv`/`.txt` | 三列 `lat,lon,value`;带 `#` 头;只支持单层 |

### 散点

列序固定为 `lon, lat, value[, value2, …]`(与 SHKit 一致),UTF-8 **带 BOM**
(Excel 打开中文表头不乱码),默认 `%.10g`。

### 系数(供 `--out-coeffs` / `convert`)

| 布局 | 扩展名 | 说明 |
| --- | --- | --- |
| `triangle` | `.sh .txt .csv .dat .tsv` | SHKit 默认;`[C; S]` 堆叠,`m` 外层 / `n` 内层 |
| `gmfcsv` | `.csv .txt` | 每行 `n,m,C,S` |
| `gfc` | `.gfc` | ICGEM/GFZ;单文件单时次 |
| `npy` | `.npy` | `(2, L+1, L+1[, ntime])` |
| `npz` | `.npz` | `C` / `S` / `meta`(JSON) |

系数文本默认用 `%.17g` 写出(17 位有效数字才能让任意 double 十进制往返无损);
散点/网格文本仍用 `%.10g`(与 SHKit 一致)。

## 退出码

| 码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1 | 运行失败(文件不存在、内容解析失败、物理量不可换算……),错误信息在 stderr 且有中文说明 |
| 2 | 命令行参数错误(argparse),例如目标来源给了两个 |
| 130 | 用户中断(Ctrl+C) |

## 输入文件识别规则(散点/网格)

**散点**

1. 有表头 → 按名字找:`lon/long/longitude/x/经度/东经`、
   `lat/latitude/y/纬度/北纬`、`value/z/data/ewh/…`;
2. 无表头 → 按通行约定:第 1 列**经度**、第 2 列**纬度**、其余列数值;
3. 表里夹着**非数值列**(例如第一列是台站名 `A,100.5,30.5,1.0`)不影响读取 ——
   那一列会被置 NaN 并给出警告,不会把整张表读崩;
4. `--lat-col` / `--lon-col` 可强制指定(数字字符串按下标解释,`"1"` = 第 2 列);
   界面上的「纬度列 / 经度列」是下拉框,第一项是「自动(留空)」;
5. 经度一律 `mod 360` 归一化到 `[0, 360)` 并记一条警告;
6. 只有两列(无数值列)时:`read_points` 会报错并提示改用 `read_positions`
   (命令行 `--points` / 界面「散点文件」那条路径本来就不需要数值列)。

**网格**

1. **按内容判型**(扩展名会撒谎):文件头是 `CDF` / `\x89HDF` → netCDF;
   `DSAA`/`DSBB` → Surfer ASCII;`DSRB`/`DSI` → Surfer 二进制(不支持);
   含 `ncols`/`nrows` → Esri ASCII;
2. `.nc` → 按 CF 找 `lat/latitude/…`、`lon/…`,选第一个依赖它们的变量
   (可用 `--grid-var` 指定);
3. **扩展名是 `.grd` 但内容是 netCDF**(GMT 的 `.grd` 就是这种)→ 按 netCDF 读,并给提示;
4. `.grd`(Surfer ASCII)→ 数据按**数值流**重排成 `(nlat, nlon)`,兼容
   "**每行 10 个数字折行**"、CRLF、UTF-8 BOM;
5. `.npy` → `(>=3, nlat, nlon)` 的 `[lon; lat; value]`;
6. `.csv/.txt/.dat` → 三列 `lat,lon,value`,pivot 成网格(数值列取"既不是纬度也
   不是经度"的那一列;重复格点值一致则去重、不一致则报错;缺格点报错);
7. 纬度轴递减会连数据一起翻转,并记 `lat_order_flipped`;经度 0..360 含端点会去重;
8. **坐标必须是经纬度**:平面/投影坐标(米)会明确报错并给出三条出路;
9. `.nc` 在网络盘上 HDF5 打不开时自动走本机临时文件中转。

完整支持表格与"为什么某些 `.grd` 读不了"的实测结论见
[README 第 5 节](../README.md#5-网格文件到底支持哪些形式)。
