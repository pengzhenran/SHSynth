# SHSynth 许可与第三方组件

> 面向"自己写的代码用 MIT、但要闭源商用"的场景,说明界面技术栈选型、
> LGPLv3 的具体义务与落地做法。
>
> **免责声明:本文由开发者整理,旨在协助合规,不构成法律意见。**
> 正式商业发行前请自行核对官方文档或咨询专业人士。
>
> 本项目与 SHKit 同源同栈,SHKit 的 `docs/许可与闭源商用说明.md` 已经把
> LGPLv3 的 5 条义务逐条落地讲透(含本机实测结论),**这里只写 SHSynth 特有
> 的部分**,重复内容不再抄一遍。

## 0. 一页速查

| 问题 | 结论 |
| --- | --- |
| SHSynth 自身代码 | **MIT**(`LICENSE.txt`) |
| 界面库能不能闭源商用? | **能**:PySide6(LGPLv3),动态链接、未修改 |
| 需要公开自己的源码吗? | **不需要**(这正是 LGPL 与 GPL 的区别) |
| 该装什么? | **`pip install PySide6-Essentials`**(不是 `PySide6`) |
| 绝对不能用什么? | **Qt Charts / Qt Data Visualization / Qt Graphs / Qt Virtual Keyboard** —— GPL-only |
| 绘图怎么办? | 用 **matplotlib**(BSD 风格许可)—— SHSynth 全部绘图都是 matplotlib |
| 要附带哪些文件? | `licenses/LGPL-3.0.txt`、`licenses/GPL-3.0.txt`、`licenses/NOTICE.txt` |
| 怎么复核? | `python tools/check_licensing.py` |

## 1. SHSynth 的技术栈与 SHKit 的差别

| | SHKit(分析) | SHSynth(综合) |
| --- | --- | --- |
| 界面 | PySide6-Essentials | PySide6-Essentials(相同) |
| 绘图 | matplotlib | matplotlib(相同) |
| GPL-only Qt 模块 | 不使用 | 不使用 |
| 额外依赖 | psutil(可选) | 无新增,反而更少 |
| 数据文件 | 勒夫数表 + 海岸线 | 同样两份(复制自 SHKit) |

**结论:闭源合规要求与 SHKit 完全一致**,SHKit 的合规做法可原样照搬。

## 2. SHSynth 特有的注意点

### 2.1 界面里没有任何 Qt Charts / Qt Data Visualization

`shsynth/gui/canvases.py` 里所有图都画在 matplotlib 的
`FigureCanvasQTAgg` 上。之所以反复强调这一点,是因为 GPL-only 的 Qt 图表模块
看起来"更省事",但一旦用上,闭源分发就直接不可能了 —— 这不是风格问题,
是许可问题。

自检:`python tools/check_licensing.py`(会逐个尝试导入 GPL-only 模块并报告)。

### 2.2 字体

界面中文依赖**系统字体**(Microsoft YaHei / SimHei / SimSun 等,通过
`QFontDatabase` 自动挑选),不随包分发字体,因此不涉及字体授权。
matplotlib 自带 DejaVu 字体为免费字体许可;中文标签用同一套系统字体。

实测:本机默认 `windows` 平台下有 213 个字体族,含上述中文字体;
`offscreen` 平台不带字体库(控件文字会显示成方框),这只是测试环境现象。

### 2.3 随包数据

| 文件 | 来源 | 许可 |
| --- | --- | --- |
| `data/coastline_110m.npz`、`data/borders_110m.npz` | Natural Earth 110m | **公有领域** |
| `data/load_love_numbers.npz`、`data/love_numbers.npy` | PREM-LLNs.dat(Wang et al. 2012) | 公开科研数据 |

## 3. 发行前自查清单

- [ ] 环境里只有 `PySide6-Essentials`,没有 `PySide6-Addons`
- [ ] 代码中**没有** `import PySide6.QtCharts` / `QtDataVisualization` / `QtGraphs`
      (`python tools/check_licensing.py` 会确认)
- [ ] 发行包内含 `licenses/LGPL-3.0.txt`、`licenses/GPL-3.0.txt`、`licenses/NOTICE.txt`
- [ ] 「帮助 → 关于」对话框里写明了使用 PySide6/Qt 及 LGPLv3
      (SHSynth 已内置)
- [ ] 用 PyInstaller `--onedir`(不是 `--onefile`)打包,Qt DLL 是独立文件
- [ ] 若写了 EULA,其中**没有**限制用户替换 Qt 库的条款
- [ ] 没有修改过 PySide6 / Qt 的源码

## 4. 打包示例

```bash
pip install PyInstaller

pyinstaller --noconfirm --clean --windowed --onedir \
  --name SHSynth \
  --exclude-module PySide6.QtCharts \
  --exclude-module PySide6.QtDataVisualization \
  --exclude-module PySide6.QtGraphs \
  --exclude-module PySide6.QtVirtualKeyboard \
  --exclude-module PySide6.QtWebEngineCore \
  --exclude-module PySide6.QtWebEngineWidgets \
  --exclude-module PySide6.QtMultimedia \
  --exclude-module PySide6.QtPdf \
  --add-data "shsynth/data;shsynth/data" \
  --add-data "licenses;licenses" \
  --add-data "docs;docs" \
  shsynth/gui/app.py
```

`packaging/shsynth.spec` 里放了一份等价的 spec 文件,可直接
`pyinstaller packaging/shsynth.spec`。
